## 🧾 Status Codes

| Code     | Meaning                            |
|----------|------------------------------------|
| `OX001`  | User registered                    |
| `OX002`  | MAC already configured             |
| `OX003`  | MAC unconfigured (proceed to setup)|
| `ERX001` | Missing registration fields        |
| `ERX002` | Duplicate entry (email/CN exists)  |
| `ERX003` | MAC address is required            |
| `ERX004` | MAC address not found              |
| `ERX500` | General server/internal error      |
